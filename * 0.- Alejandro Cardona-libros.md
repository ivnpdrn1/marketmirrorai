### Paso 3: agregar referencia en TOOLS.md

Añade esto al final de `TOOLS.md`:

```markdown
## Proprietary Trend Method Library

Location:

/home/ubuntu/marketmirrorai/knowledge/trend-methods/

Purpose:

MarketMirrorAI may study uploaded PDF materials describing disciplined techniques for anticipating trend changes for CALL and PUT opportunities.

These materials should be used as reference knowledge, not as automatic trading instructions.

The agent must evaluate whether each technique is useful, testable, explainable, and consistent with current market evidence.

Any technique extracted from the PDFs must be converted into:

- Clear rules
- Required evidence
- Confirmation signals
- Failure conditions
- Historical validation notes
- Risk warnings

Never execute trades automatically.
```

### Paso 4: agregar en MEMORY.md

```markdown
## Method Library

A proprietary trend-change method library will be added through PDF documents.

These documents describe techniques for anticipating trend changes for CALL and PUT opportunities.

The agent should study, summarize, test, and evaluate these methods before using them in alerts.

No method should be treated as valid until it is observed, tested, and reviewed.
```

La idea correcta no es que OpenClaw “obedezca” los libros directamente.

La idea es:

**PDF → resumen → reglas → pruebas → alertas → resultados → memoria.**

La imagen muestra que estás aquí:

```bash
ubuntu@ip-172-26-0-48:~$
```

El símbolo `~` significa:

```bash
/home/ubuntu
```

Por tanto:

```bash
~
=
/home/ubuntu
```

Cuando te dije:

```bash
/home/ubuntu/marketmirrorai/knowledge/trend-methods
```

sería una carpeta nueva dentro de tu directorio principal.

```bash
/home/ubuntu
│
├── .openclaw
│   └── workspace
│
└── (otras carpetas)
```

```bash
pwd
```

verás exactamente:

```bash
/home/ubuntu
```

Y si estás dentro de OpenClaw:

```bash
cd ~/.openclaw/workspace
pwd
```

verás:

```bash
/ home / ubuntu / .openclaw / workspace
```

(quitando los espacios).

Para MarketMirrorAI yo comenzaría creando una estructura independiente de OpenClaw:

```bash
mkdir -p ~/marketmirrorai
```

Quedaría:

```bash
/home/ubuntu
│
├── .openclaw
│
└── marketmirrorai
    ├── knowledge
    ├── data
    ├── alerts
    ├── logs
    ├── reports
    └── backtests
```

```bash
mkdir -p ~/marketmirrorai/knowledge/trend-methods

mkdir -p ~/marketmirrorai/backtests
mkdir -p ~/marketmirrorai/reports
```

Verifica con:

```bash
tree ~/marketmirrorai
```

```bash
sudo apt install tree -y
```

---

La razón para separarlo de `.openclaw` es importante:

**OpenClaw es el agente.**

**MarketMirrorAI es el proyecto.**

Mañana podrías tener:

```text
OpenClaw
    ├─ MarketMirrorAI
    ├─ Vision-AI
    └─ byDebut
```

y todos compartirían la misma filosofía:

* OpenClaw = cerebro/agente.
* MarketMirrorAI = conocimiento financiero.
* Vision-AI = conocimiento de visión artificial.
* byDebut = conocimiento editorial/literario.

Es una estructura mucho más escalable para lo que quieres construir a largo plazo.



Ese será el corazón profesional del Shadow Agent.
