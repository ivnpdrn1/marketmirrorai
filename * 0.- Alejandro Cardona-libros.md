Sí. Esos PDFs deben ir en una **base de conocimiento común**, no solo dentro del chat de OpenClaw.

La estructura correcta sería:

```bash
/home/ubuntu/marketmirrorai/knowledge/trend-methods/
```

Ahí colocas los 4 PDFs.

Luego ambos paths los usan:

```text
Primary Workflow
        │
        ▼
/marketmirrorai/knowledge/trend-methods/

OpenClaw Shadow Agent
        │
        ▼
/marketmirrorai/knowledge/trend-methods/
```

### Paso 1: crear carpeta

```bash
mkdir -p /home/ubuntu/marketmirrorai/knowledge/trend-methods
mkdir -p /home/ubuntu/marketmirrorai/knowledge/summaries
mkdir -p /home/ubuntu/marketmirrorai/knowledge/tests
```

### Paso 2: cuando tengas los PDFs

Subirlos ahí:

```bash
/home/ubuntu/marketmirrorai/knowledge/trend-methods/book-01.pdf
/home/ubuntu/marketmirrorai/knowledge/trend-methods/book-02.pdf
/home/ubuntu/marketmirrorai/knowledge/trend-methods/book-03.pdf
/home/ubuntu/marketmirrorai/knowledge/trend-methods/book-04.pdf
```

### Paso 3: agregar referencia en TOOLS.md

Añade esto al final de `TOOLS.md`:

```markdown
## Proprietary Trend Method Library

Location:

/home/ubuntu/marketmirrorai/knowledge/trend-methods/

Purpose:

MarketMirrorAI may study uploaded PDF materials describing disciplined techniques for anticipating trend changes for CALL and PUT opportunities.

These materials should be used as reference knowledge, not as automatic trading instructions.

The agent must evaluate whether each technique is useful, testable, explainable, and consistent with current market evidence.

Any technique extracted from the PDFs must be converted into:

- Clear rules
- Required evidence
- Confirmation signals
- Failure conditions
- Historical validation notes
- Risk warnings

Never execute trades automatically.
```

### Paso 4: agregar en MEMORY.md

```markdown
## Method Library

A proprietary trend-change method library will be added through PDF documents.

These documents describe techniques for anticipating trend changes for CALL and PUT opportunities.

The agent should study, summarize, test, and evaluate these methods before using them in alerts.

No method should be treated as valid until it is observed, tested, and reviewed.
```

La idea correcta no es que OpenClaw “obedezca” los libros directamente.

La idea es:

**PDF → resumen → reglas → pruebas → alertas → resultados → memoria.**

Ese será el corazón profesional del Shadow Agent.
