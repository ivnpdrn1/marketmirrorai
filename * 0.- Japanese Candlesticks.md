# Lo que realmente enseñan los libros

Cuando el autor explica:

```text
Piso Fuerte
Primer Gap al Alza
Canal Bajista
Ruptura del Piso del Gap
Primera Vela Roja
```

no empieza diciendo:

```text
Open = 103.4
Close = 105.2
Volume = 1.2M
```

Empieza mostrando:

```text
una gráfica
```

y después dice:

```text
"esto es un Piso Fuerte"

"esto es un Primer Gap al Alza"

"esto es un Canal Bajista"
```

Es decir:

```text
La imagen genera el diagnóstico.

El texto explica el diagnóstico.
```

No al revés.

# Lo que hacen los fondos cuantitativos modernos

Muchos fondos hoy combinan:

```text
Numerical Features
+
Visual Features
```

porque algunos patrones son extremadamente difíciles de describir con reglas puras.

Por ejemplo:

```text
Canal Bajista
```

es trivial para el ojo humano.

Pero es difícil expresarlo completamente con:

```text
if x
if y
if z
```

En cambio una imagen de velas muestra el patrón instantáneamente.
