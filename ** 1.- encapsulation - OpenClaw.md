## Arquitectura recomendada

```text
APIs / News / Market Data
        ↓
AWS Workflow oficial
        ↓
DynamoDB / Postgres / S3
        ↓
          ┌────────────────────────────┐
          │ OpenClaw Shadow Agent       │
          │ SOLO LECTURA                │
          │ NO escribe / NO modifica    │
          └────────────────────────────┘
        ↓
Comparador de resultados
```

## Dónde colocarlo

La mejor opción:

**Una EC2 separada o container separado**, sin permisos de escritura.

| Componente    | Recomendación                             |
| ------------- | ----------------------------------------- |
| Lugar         | EC2 pequeña separada                      |
| Red           | Security Group aislado                    |
| Permisos AWS  | IAM role read-only                        |
| Base de datos | Usuario read-only                         |
| S3            | Bucket/prefix read-only                   |
| Alertas       | Canal separado de Telegram                |
| Output        | Tabla separada: `openclaw_shadow_outputs` |

OpenClaw es más un agente personal/autónomo que una librería tradicional tipo LangGraph, por eso conviene usarlo como proceso aislado y gobernado, no como parte interna del pipeline oficial. ([OpenClaw][1])

## Regla central

OpenClaw puede ver:

```text
noticias
datos de mercado
salidas del LLM oficial
razonamientos
alertas generadas
resultados posteriores
```

Pero NO puede tocar:

```text
EventBridge
Lambda
Secrets Manager
Telegram oficial
DynamoDB principal
código productivo
configuración AWS
modelos oficiales
```

## Cómo comparar ambos workflows

Crea dos salidas separadas:

```text
official_llm_outputs
openclaw_shadow_outputs
```

Luego una Lambda diaria compara:

| Métrica          | Qué mide                                  |
| ---------------- | ----------------------------------------- |
| Timing           | quién detectó antes                       |
| Similarity score | quién encontró mejores espejos históricos |
| Confidence       | quién calibró mejor                       |
| False positives  | alertas malas                             |
| False negatives  | oportunidades perdidas                    |
| Outcome accuracy | resultado real 1h, 1d, 1w                 |

## La forma más segura

```text
OpenClaw → lee copias
OpenClaw → escribe solo en su sandbox
OpenClaw → nunca ejecuta acciones oficiales
```

Así madura en paralelo sin riesgo. Cuando demuestre mejores resultados, lo promueves gradualmente de **observador** a **co-analista**, y después, si se justifica, a **supervisor autónomo**.
