### Lo más importante que veo ahora

Hay algo que aún no está modelado y que considero fundamental para MarketMirrorAI:

```text
Pattern Registry
```

Actualmente tienes:

```text
MMAI-001
MMAI-002
...
MMAI-015
```

dispersos en varios directorios.

Yo crearía después:

```bash
nano patterns/MMAI_MASTER_REGISTRY.md
```

que sea la tabla maestra.

Ejemplo:

```text
MMAI-001
Name: Piso Fuerte SPY
Type: Bullish
Signal: CALL
Visual Required: Yes
Validation Status: Pending

MMAI-002
Name: Primer Gap al Alza
Type: Bullish
Signal: CALL
Visual Required: Yes
Validation Status: Extracted
```

¿Por qué?

Porque cuando OpenClaw tenga 50, 100 o 200 patrones, necesitará una única fuente para responder:

```text
¿Cuáles patrones existen?
¿Cuáles están validados?
¿Cuáles requieren visión?
¿Cuáles generan CALL?
¿Cuáles generan PUT?
```

Sin recorrer cientos de archivos.
